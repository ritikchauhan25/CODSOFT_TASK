# CODSOFT Data Analytics Internship

This repository contains my completed tasks for the CODSOFT Data Analytics Internship, covering data cleaning, exploratory data analysis, and data visualization using Python and Power BI.

## Task 1: Data Cleaning and Preprocessing

### Project Overview
Cleaned and preprocessed the Telco Customer Churn dataset using Python and Pandas to prepare the data for further analysis.

### Dataset
The dataset includes customer demographics, services, tenure, contract details, monthly charges, total charges, and churn status.

### Data Cleaning Steps
1. Imported and inspected the dataset using Pandas.
2. Checked missing values and duplicate records.
3. Identified incorrect data types in `TotalCharges`.
4. Converted `TotalCharges` to a numeric data type.
5. Identified 11 blank values in `TotalCharges`.
6. Handled missing values and checked categorical values for consistency.
7. Exported the cleaned dataset to CSV.

### Files
- `CODSOFT_Task1_Data_Cleaning.ipynb` — Data cleaning notebook.
- `cleaned_telco_customer_churn.csv` — Cleaned dataset.

### Conclusion
Prepared the dataset for further analysis by checking data quality, correcting data types, and handling missing values.

## Task 3: Data Visualization

### Project Overview
Analyzed and visualized the Telco Customer Churn dataset using Python and Power BI to explore customer churn patterns and factors related to customer retention.

### Python Visualizations
- Customer churn distribution using bar and pie charts.
- Customer tenure distribution using a histogram.
- Contract type vs. churn.
- Monthly charges distribution using a box plot.
- Customer tenure vs. monthly charges using a scatter plot.
- Internet service vs. churn.
- Payment method vs. churn.
- Average monthly charges by churn status.

### Power BI Dashboard
Created a multi-page interactive dashboard featuring:

- **Overview Dashboard:** Total customers, churned customers, churn rate, contract type, and internet service analysis.
- **Churn Analysis:** Customer tenure, monthly charges, payment method, and tech support analysis.
- **Interactive Filters:** Slicers for churn, contract, internet service, and payment method.

### Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Power BI
- Jupyter Notebook / Google Colab

### Files
- `CODSOF_TASK3.ipynb` — Python data visualization notebook.
- `CODSOFT_Task3_Dashboard.pbix` — Power BI dashboard.
- `cleaned_telco_customer_churn.csv` — Dataset used for analysis.

### Conclusion
Visualized customer churn patterns and compared customer segments to support data-driven analysis of customer retention.
